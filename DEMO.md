# Demo script (about 4 minutes)

1. Open http://localhost:4000. Click **Arjun Sharma** (employee).
2. **Apply** → pick a 5-day range in the future, reason "Family vacation". The page shows "5 days — a supporting document is required". Submit without a document: a friendly red message explains what to do.
3. Attach any PDF or image and submit. Open the request: status *Pending manager* (amber), badge *Long leave*.
4. Sign out. Click **Rahul Mehta** (manager). Open the request from **Approval queue**. Try **Reject** with no comment: it asks for a reason. Click **Ask for more information** with the question "Which flight are you on?".
5. Sign out, sign in as Arjun again. Open the request (*Info requested*, purple), type a reply and send. It returns to the manager.
6. As Rahul, **Approve**. Status becomes *Awaiting HOD* (blue).
7. Sign out, click **Priya Nair** (HOD). **Approval queue** shows the request with Rahul's comment. **Approve**: *Approved* (green).
8. As Priya open **Audit log**: sign-ins, the submission, the info request, both approvals, document views, with IP and status changes.
9. Optional: as **Imran Khan**, Apply for any leave: blocked, because an earlier emergency leave still needs documents. As Arjun, tick *Emergency leave* on a 5-day request: allowed without documents.
10. Resize the window to phone width: lists become stacked cards.
